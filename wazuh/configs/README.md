# Wazuh Configurations

Configuraciones del manager y agentes utilizadas en el lab.

---

## Archivos

| Archivo | Descripción |
|---|---|
| `ossec.conf.manager` | Configuración base del Wazuh Manager |
| `ossec.conf.agent-linux` | Configuración del agente Linux |
| `ossec.conf.agent-windows` | Configuración del agente Windows |
| `sysmon-config.xml` | Config de Sysmon (SwiftOnSecurity) |

---

> Los archivos se agregan conforme se ajustan durante los escenarios.
